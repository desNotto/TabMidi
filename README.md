# TabMidi

Автор: **desNotto**

VST3-плагин для гитариста: быстро записать или загрузить табулатуру, превратить её в MIDI и одним движением перетащить в проект DAW. Звука плагин не издаёт, это рабочая панель. Для DAW он определяется как инструмент (так он виден везде), а результат его работы — готовые `.mid`-файлы.

Что внутри окна: пресеты, импорт файлов Guitar Pro, редактор табулатуры на 6–9 струн, виртуальный гриф на 24 лада с подсветкой тональности, подсказка по аккордам тональности, определение аккордов и интервалов, редактор строя, свои тональности.

---

## 1. Как получить плагин (сборка на GitHub, без установки программ)

1. Создайте на GitHub пустой репозиторий и загрузите в него все файлы из этой папки (*Add file → Upload files*). Скрытая папка `.github` при загрузке через браузер обычно пропадает, это нормально: файл сборки создаётся вручную (шаг 2).
2. Добавьте файл сборки одним из способов:
   * вкладка **Actions → set up a workflow yourself**: откроется редактор, вставьте в него весь текст из файла `workflow-build.yml` и нажмите *Commit changes*;
   * или *Add file → Create new file*, в поле имени наберите `.github/workflows/build.yml` (слэши создают папки), вставьте тот же текст и нажмите *Commit changes*.
   Если репозиторий уже создан: загрузите файлы поверх (файлы с теми же именами заменятся), а файл сборки обновите вручную: откройте `.github/workflows/build.yml` → значок карандаша → вставьте текст из `workflow-build.yml` → *Commit changes*.
3. Сборка (только Windows) стартует сама после коммита или вручную: *Actions → Build VST3 (Windows) → Run workflow*. Через ~10 минут внизу страницы запуска появятся **Artifacts**:
   * `TabMidi-VST3-Windows` — папка `TabMidi.vst3`;
   * `TabMidi-Standalone-Windows` — отдельная программа для проверки без DAW.
4. Положите папку `TabMidi.vst3` в `C:\Program Files\Common Files\VST3\` и пересканируйте плагины в DAW.

### Локальная сборка

Нужны CMake ≥ 3.22 и Visual Studio 2022 (или Xcode / gcc). JUCE скачивается автоматически.

```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target TabMidi_VST3
```

Результат: `build/TabMidi_artefacts/Release/VST3/TabMidi.vst3`.

## 2. Окно плагина

Сверху вниз:

| Блок | Что в нём |
|---|---|
| **Пресет** | выбор, сохранение, переименование и удаление пресетов (раздел 8) |
| **Импорт и MAKE MIDI** | зона для файла Guitar Pro, список дорожек, кнопка **MAKE MIDI**, зона перетаскивания MIDI в DAW, кнопки «Сохранить…» и «Раздельно / Одним файлом» |
| **Настройки** | число тактов (4 / 8 / 16), число струн (6–9), строй и ноты каждой струны, длительность новой ноты |
| **Таб** | сама табулатура, кнопки «Видно тактов», «Копировать», «Вставить», «Очистить», «Отменить» |
| **Гриф** | выбор тональности (нота и лад), строка с названием выбранного аккорда, виртуальный гриф на 24 лада |
| **Аккорды тональности** (справа) | таблица всех аккордов; аккорды из выбранной тональности подсвечены |

Окно тянется за правый нижний угол, элементы подстраиваются: лишняя высота достаётся грифу, лишняя ширина — табу и грифу. Минимальный размер 1546×764. Размер запоминается вместе с проектом DAW.

При первом открытии стоит: 8 струн, строй Drop E, тональность E minor, 4 такта.

## 3. Guitar Pro → MIDI

* Перетащите файл `.gpx` (Guitar Pro 6) или `.gp` (Guitar Pro 7 / 8) в окно плагина или нажмите «Открыть…». Файлы Guitar Pro 5 и старше не поддерживаются.
* В MIDI уходят **все дорожки файла**: гитары, бас, клавиши, струнные, духовые, ударные. Повторы и вольты разворачиваются, триоли, размеры и смена темпа сохраняются точно (запись идёт с разрешением 480 тиков на четвертную).
* В редакторе открывается одна дорожка: гитара на 6–9 струнах с наибольшим числом нот. Другую можно выбрать в списке рядом с кнопкой «Открыть…». Правки, сделанные в редакторе, попадают в MIDI своей дорожки, а при переключении на другую дорожку не теряются.
* **MAKE MIDI** создаёт файлы, а зона **«В DAW: N дорожек»** тянется в проект DAW одним движением сразу со всеми файлами.
  * Режим «Раздельно» (по умолчанию): отдельный `.mid` на каждую дорожку, имена вида `Песня - 03 Название дорожки.mid`.
  * Режим «Одним файлом»: один `.mid` с отдельной MIDI-дорожкой и отдельным каналом на каждую дорожку Guitar Pro; ударные на канале 10.
  * Кнопка «Раздельно / Одним файлом» переключает режим; если файлы уже созданы, они пересоздаются.
  * Кнопка «Сохранить…» кладёт результат в выбранное место (в раздельном режиме выбирается папка для всех файлов) — на случай, если ваш DAW не принимает перетаскивание из окна плагина.
* Файлы создаются в папке `Temp\TabMidi\export`; при каждом новом MAKE MIDI она очищается.
* Для табулатуры, написанной вручную, получается один `.mid`.

## 4. Редактор табулатуры

* Число тактов: **4 / 8 / 16** (кнопки «Такты»). Число струн: **6 / 7 / 8 / 9**. Смена числа струн выставляет стандартный строй для этого количества.
* **Видно тактов 4 / 8 / 16** задаёт, сколько тактов помещается в окно сразу (остальные доступны прокруткой). Это работает и для пустого стана: выбранное число тактов сразу отображается, стан при необходимости удлиняется. На 16 тактах цифры мелкие, это обзорный режим.
* **Ввод ноты:** клик по ячейке (выбирается ячейка и струна) и цифры 0–9 (ладов 10–36: два быстрых нажатия подряд). Или клик по ноте на виртуальном грифе — он вписывает эту ноту в выбранную ячейку; повторный клик по той же ноте убирает её.
* **Длительность:** кнопки «Целая / 1/2 / 1/4 / 1/8 / 1/16» в блоке настроек. Нажатие на кнопку при выбранном аккорде меняет длительность всего аккорда.
* **Сетка строго следует длительности.** Целая нота записывается только в начале такта, половинная в начале и в середине, четвертная на каждой доле и так далее. Клик по табу попадает в ближайшую ячейку этой сетки (или в уже записанную ноту на этой струне), курсор имеет ширину той ноты, которая будет записана. Нота не может пересечь тактовую черту: если места в такте меньше, длительность обрезается по границе.
* **Аккорды:** если в одной ячейке несколько нот, длительность новой ноты берётся от нот, которые уже стоят там.
* **Подписи над табом:** имя аккорда (Am, F, C/E, G7…). Для двух нот подписывается интервал: **м3, б3, ч4, ч5, тритон, м7** и т. д. (см. раздел 6).
* **Выделение:** протяжка мышью по табу, Shift + клик, Shift + `←` / `→`, двойной клик (такт целиком), клик по номеру такта (Shift — несколько тактов подряд), `Ctrl+A` (всё). Выделенное можно **копировать, вырезать, вставлять, очищать**. Вставка идёт с начала выделения (или с текущей ячейки). Буфер обмена общий для всех копий плагина, так что фрагмент можно перенести в другой проект.
* **Отмена:** `Ctrl+Z` или кнопка «Отменить» (до 40 шагов).

## 5. Виртуальный гриф

* **24 лада.** Лады укорачиваются к корпусу, как на настоящей гитарной шейке. На широких ладах нота и ступень подписаны рядом («E 5»), на узких в две строки.
* Число струн следует за выбранным строем (6–9).
* **Тональность**: выбираются нота тоники и лад (Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Harmonic minor, Melodic minor, пентатоники и ваши собственные). На каждой отметке написаны нота и номер ступени, тоника оранжевая.
* **Открытые струны** подписаны всегда; если нота вне тональности, она показана бледно.
* **Обводка:** ноты выбранного в табе столбца обведены белым — видно, где именно сыграны ноты аккорда.
* **Подсказка по аккордам** (панель справа): столбец на каждую ноту лада, строка на каждый тип аккорда (maj, min, sus2, sus4, 7, maj7, m7, 7b5, 7#5, m7b5, minmaj7, 7sus4, 6, min6, 6add9, 9, maj9, m9, minmaj9, add9, m add9, 11). Аккорды, целиком состоящие из нот тональности, подсвечены.
  * Клик по аккорду показывает на грифе его ноты, а вместо ступеней тональности подписаны ступени самого аккорда (1, ♭3, 5, ♭7, 9…). Ноты тональности, не входящие в аккорд, остаются на грифе, но приглушены. Повторный клик по тому же аккорду возвращает обычный вид.
  * Над грифом появляется строка: название аккорда, в скобках другие названия тех же нот, ступени и ноты. Например: **Emin7 (G6/E)  |  ступени 1 ♭3 5 ♭7  |  ноты E G B D**.
  * При смене тональности выбор аккорда сбрасывается.

## 6. Определение интервалов и аккордов

Плагин называет то, что вы записали в табе, начиная с первой же ноты:

* **две ноты** — интервал: малая / большая терция, чистая кварта и квинта, тритон, секста, септима, нона и так далее. Рядом даётся обращение («обращение: м6»), для квинты и кварты ещё power-аккорд (E5);
* **три и больше** — аккорд, самая нижняя нота считается басом: Em, Em7, C/E, Am7/G, Cdim7, E7#9, Cmaj9, C13, voicing без квинты (7 no5, 6 no5) и многое другое — в базе 70 форм аккордов (трезвучия, шестые, септаккорды, ноны, ундецимы, терцдецимы, альтерированные и без квинты);
* **другие названия** тех же нот показываются в скобках (например, Em7 — это и G6/E; уменьшённый септаккорд — четыре варианта), для обращений указывается номер («1-я инверсия») или нота в басу;
* набор нот, которого нет в базе, показывается как «Набор нот» со ступенями от баса.

Название выбранного столбца таба показывается в строке над грифом, а короткое — над самим табом.

## 7. Строй и тональности

* **Строй**: список готовых строев (Standard, Drop D, Drop C, DADGAD, Open G, Drop A, Drop E, Drop B и др.) и ноты всех струн на кнопках; клик по ноте открывает редактор строя.
* **Редактор строя**: кнопки − и + у каждой струны меняют её ноту на полутон; кнопки «Весь строй» − и + двигают все струны сразу. Свой строй можно назвать, сохранить («★ Сохранить строй») и удалить.
* **Свои тональности**: в списке лада пункты «+ Новая тональность…» и «Изменить выбранную…». Отмечаются ноты над тоникой (от 3 до 8 нот), можно взять за основу готовый лад. Тональность сохраняется, меняется и удаляется, она появляется в списке, в подсказке по аккордам и сохраняется в проекте.

## 8. Пресеты

Пресет — это сохранённая настройка: **строй (с числом струн) и тональность**. Ноты таба в пресет не входят, поэтому выбор пресета ничего не стирает в табе.

* **Заводские:** «8 Strings - Drop E - E minor» и «9 Strings - Drop B - B minor».
* **Сохранить**: имя вводится в окошке (по умолчанию «Мой пресет»). Если пресет с таким именем уже есть, плагин спрашивает «Перезаписать?». Имена заводских пресетов занять нельзя.
* **Переименовать** и **Удалить** (с подтверждением) доступны, когда текущие настройки совпадают с вашим пресетом. Если переименовать на имя другого пресета, плагин тоже спросит о перезаписи.
* Если вы изменили строй или тональность вручную и это не совпадает ни с одним пресетом, в списке написано «Свои настройки».

## 9. Горячие клавиши в табе

| Действие | Клавиши |
|---|---|
| Ввести лад | цифры `0`–`9` |
| Стереть ноту | `Delete` / `Backspace` или правый клик |
| Перемещение | стрелки; `Enter` / пробел — на длину ноты вправо; `Home` — в начало |
| Выделить | протянуть мышью; Shift + клик; Shift + `←` `→`; двойной клик — такт; `Ctrl+A` — всё; `Esc` снимает выделение |
| Копировать / вырезать / вставить | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Очистить выделенное | `Delete` при выделении |
| Отменить | `Ctrl+Z` |

Если ваш DAW перехватывает клавиши, всё можно делать мышью: ноты вводятся кликом по грифу, а с выделением работают кнопки над табом.

## 10. Что где хранится

* **В проекте DAW**: табулатура, строй, тональность, длительность по умолчанию, «видно тактов», размер окна, выбранная тональность вместе с её нотами. Импортированные дорожки, кроме открытой в редакторе, в проект не сохраняются: после повторного открытия проекта MAKE MIDI выдаст только то, что в табе.
* **В папке пользователя** (`%APPDATA%\TabMidi\`): `tunings.json` (свои строи), `scales.json` (свои тональности), `presets.json` (свои пресеты).
* **Во временной папке**: `Temp\TabMidi\export` — последние созданные `.mid`.

## 11. Ограничения

* Не поддерживаются файлы Guitar Pro 5 и старше (`.gp5`, `.gp4`, `.gp3`).
* В редакторе открываются только гитарные дорожки с 6–9 струнами; остальные дорожки (бас, клавиши, ударные…) только экспортируются в MIDI.
* Ударные из Guitar Pro 6 (`.gpx`) переводятся в ноты General MIDI по стандартной таблице, это приближённое соответствие; в `.gp` (7/8) берутся ноты самого файла.
* В редакторе максимум 64 такта; при импорте длинной песни в MIDI попадает всё, а в окне показаны первые 64.
* После правки таба вручную MIDI этой дорожки строится из сетки 1/16: точная запись триолей остаётся только у неотредактированных дорожек.
* Плагин не воспроизводит звук и не играет MIDI по транспорту DAW.
* Перетаскивание нескольких файлов зависит от DAW; если он принимает только один, используйте режим «Одним файлом» или «Сохранить…».

## 12. Устройство проекта

```
CMakeLists.txt            проект (JUCE подтягивается через FetchContent)
workflow-build.yml        файл сборки GitHub Actions (копия лежит в .github/workflows/build.yml)
Source/Theory.h           ноты, лады, строи, аккорды и интервалы, пресеты, хранилища пользователя
Source/TabModel.*         модель таба, экспорт в MIDI (одна дорожка и несколько), сохранение состояния
Source/GpxImporter.*      чтение .gpx (BCFZ/BCFS) и .gp, разбор score.gpif, все дорожки
Source/PluginProcessor.*  плагин: состояние проекта, MAKE MIDI (раздельно / одним файлом)
Source/PluginEditor.*     окно: таб, гриф, подсказка по аккордам, пресеты, редакторы строя и тональности
tests/                    консольный тест импорта и проверочная программа (поведение, скриншоты окна)
```

Тест импорта Guitar Pro: `cmake -B build -DTABMIDI_TESTS_ONLY=ON && cmake --build build --target TabMidiTest`, запуск: `TabMidiTest файл.gpx`.

## Лицензия

JUCE распространяется по AGPLv3 или по коммерческой лицензии. Для личного использования проблем нет; если захотите раздавать собранный плагин другим людям, нужно либо открыть исходники под AGPLv3, либо купить лицензию JUCE.
