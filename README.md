# TabMidi

Автор: **desNotto**.

VST3-плагин для быстрой записи риффов: табулатура → MIDI → в проект DAW.

* **Импорт Guitar Pro**: перетащите `.gpx` (Guitar Pro 6) или `.gp` (Guitar Pro 7/8) в окно плагина. Если в файле несколько гитарных дорожек, выберите нужную в списке (по умолчанию берётся самая «нотная»). Повторы и вольты разворачиваются, триоли и размеры сохраняются точно.
* **Свой таб**: 4 / 8 / 16 тактов (по умолчанию 4). Сколько тактов видно в окне сразу, выбирается кнопками «Видно тактов» 4 / 8 / 16 (на 16 такта цифры мелкие, это обзорный режим), гитары на 6–9 струн, нота на каждой струне. Имя аккорда подписывается над столбцом автоматически (Am, F, C/E, G7…).
* **Длительность**: кнопки справа от строя — целая, половина, четверть, восьмая, шестнадцатая. Сетка таба строго следует выбранной длительности: целая нота пишется только в начале такта, половина в начале и в середине, четверть на каждой доле и так далее, поэтому нота не может пересечь тактовую черту. Клик по табу попадает в ближайшую ячейку этой сетки (или в уже записанную ноту на этой струне), а курсор имеет ширину той ноты, которая будет записана. Нажатие на кнопку длительности при выбранном аккорде меняет длительность всего аккорда.
* **MAKE MIDI**: из файла Guitar Pro в MIDI уходят **все дорожки** (гитары, бас, клавиши, струнные, духовые, ударные), а не только та, что открыта в редакторе. По умолчанию создаётся отдельный `.mid` на каждую дорожку, и зона «В DAW: N дорожек» перетаскивается в проект **одним движением сразу со всеми файлами**. Кнопка «Раздельно / Одним файлом» переключает режим: во втором получается один `.mid` с отдельным MIDI-каналом на каждую дорожку (ударные на канале 10). «Сохранить…» кладёт файлы в выбранную папку, если ваш DAW не принимает перетаскивание. Правки, сделанные в редакторе, попадают в MIDI своей дорожки.
* **Строй**: нота каждой струны меняется отдельно (кнопки − и +, шаг в полутон; пара кнопок «Весь строй» поднимает или опускает сразу все струны), есть готовые строи, свои строи сохраняются кнопкой «★ Сохранить строй» и хранятся в `%APPDATA%\TabMidi\tunings.json`, свои тональности — рядом, в `scales.json` (macOS: `~/Library/Application Support/TabMidi/`).
* **Гриф**: нота тоники и лад выбираются над грифом (Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Harmonic/Melodic minor, пентатоники). Свою тональность можно создать, изменить и удалить через пункты «+ Новая тональность…» и «Изменить выбранную…» в списке лада (отмечаете ноты над тоникой, от 3 до 8 нот). На каждой отметке написаны нота и номер ступени, тоника оранжевая. Гриф на 24 лада: лады укорачиваются к корпусу, как на настоящей гитаре, а на узких ладах нота и ступень подписаны в две строки. Количество струн следует за выбранным строем. Открытые струны подписаны всегда (вне тональности — бледным цветом). Ноты выбранного в табе аккорда обведены белым. Клик по грифу добавляет эту ноту в выбранную ячейку таба, повторный клик по той же ноте убирает её из таба.
* **Размер окна**: окно тянется за правый нижний угол, элементы подстраиваются, лишняя высота достаётся грифу, лишняя ширина — табу и грифу. Размер запоминается вместе с проектом. Минимальный размер окна 1546×724.
* **Подсказка по аккордам** (панель справа, видна всегда): таблица аккордов тональности, столбец на каждую ноту лада, строка на каждый тип аккорда (maj, min, sus2, 7, maj7, m9, add9, 11 и т.д.); аккорды, целиком состоящие из нот тональности, подсвечены. Клик по аккорду показывает на грифе только его ноты, а вместо ступеней тональности подписаны ступени самого аккорда (1, b3, 5, b7, 9…). Повторный клик по тому же аккорду возвращает ноты и ступени тональности. При смене тональности выбор аккорда сбрасывается.
* **Такты**: выделять можно протягиванием мыши по табу (классическое выделение), Shift + клик или Shift + стрелки, двойным кликом по ячейке (такт целиком) и кликом по номеру такта (с Shift — несколько тактов подряд). Выделенное можно копировать, вставлять, вырезать и очищать кнопками над табом или клавишами. Вставка идёт с выделенного такта (или с такта, где стоит курсор). Буфер общий для всех копий плагина, так что такт можно перенести между проектами. Любое действие отменяется (Ctrl+Z).

## Как собрать VST3 без установки чего-либо на свой компьютер

1. Создайте на GitHub пустой репозиторий и загрузите в него все файлы из этой папки (кнопка *Add file → Upload files*). Папка `.github` при загрузке через браузер обычно пропадает, это нормально, её создадим на шаге 2.
2. Добавьте файл сборки одним из способов:
   * вкладка **Actions → set up a workflow yourself**: откроется редактор, вставьте в него весь текст из файла `workflow-build.yml` и нажмите *Commit changes*;
   * или *Add file → Create new file*, в поле имени наберите `.github/workflows/build.yml` (слэши создают папки), вставьте тот же текст и нажмите *Commit changes*.
   Если репозиторий уже создан: загрузите файлы поверх (файлы с теми же именами заменятся), а файл сборки обновите вручную: откройте `.github/workflows/build.yml` на GitHub → значок карандаша → вставьте текст из `workflow-build.yml` → *Commit changes*.
3. Сборка (только Windows) стартует сама после этого коммита (или вручную: Actions → Build VST3 → *Run workflow*). Через ~10 минут внизу страницы завершённого запуска появятся **Artifacts**:
   * `TabMidi-VST3-Windows` — папка `TabMidi.vst3`;
   * `TabMidi-Standalone-Windows` — отдельная программа для проверки без DAW;
4. Положите `TabMidi.vst3` в `C:\Program Files\Common Files\VST3\` и пересканируйте плагины в DAW. Плагин определяется как инструмент (так он виден во всех DAW); звука он не издаёт, это рабочая панель, которая создаёт `.mid`-файлы.

## Локальная сборка

Нужны CMake ≥ 3.22 и компилятор C++17 (Visual Studio 2022 / Xcode / gcc). JUCE скачивается автоматически.

```
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release --target TabMidi_VST3
```

Результат: `build/TabMidi_artefacts/Release/VST3/TabMidi.vst3`.

**При первом открытии** плагин стоит на 8 струнах, строй Drop E, тональность E Minor, 4 такта; "Видно тактов" 4 / 8 / 16 меняет вид и у пустого стана (стан удлиняется до выбранного количества тактов).

## Горячие клавиши в табе

| Действие | Клавиши |
|---|---|
| Выбрать ячейку | клик (правый клик стирает ноту) |
| Ввести лад | цифры; два быстрых нажатия подряд дают лад 10–36 |
| Стереть ноту | `Delete` / `Backspace` |
| Выделить ячейки | протянуть мышью по табу, Shift + клик, Shift + `←` / `→`, `Ctrl+A` — всё; `Esc` снимает выделение |
| Выделить такт | двойной клик по ячейке или клик по номеру такта (Shift — несколько тактов) |
| Копировать / вырезать / вставить такт | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` или кнопки над табом |
| Очистить такт | `Delete` при выделенном такте или кнопка «Удалить такт» |
| Отменить | `Ctrl+Z` или кнопка «Отменить» |
| Перемещение | стрелки; `Enter` / пробел — на длину текущей ноты вправо; `Home` — в начало |
| Длительность | кнопки «Длительность»: для новых нот, а на выбранном аккорде меняют его длину |

Если ваш DAW перехватывает клавиши, ноты можно вводить мышью (клик по грифу), а с тактами работать кнопками над табом.

## Что внутри

```
CMakeLists.txt            проект (JUCE подтягивается через FetchContent)
Source/Theory.h           ноты, лады, строи, определение аккордов
Source/TabModel.*         модель таба, экспорт в MIDI, сохранение состояния
Source/GpxImporter.*      чтение .gpx (BCFZ/BCFS) и .gp, разбор score.gpif
Source/PluginProcessor.*  сам плагин (состояние проекта хранится в сессии DAW)
Source/PluginEditor.*     окно: таб, гриф, редактор строя, перетаскивание MIDI
tests/                    консольный тест импорта и утилита для скриншотов окна
.github/workflows/        сборка на GitHub Actions (копия лежит в workflow-build.yml)
workflow-build.yml        тот же файл сборки, видимый для загрузки через браузер
```

## Известные ограничения первой версии

* Ударные из Guitar Pro 6 (`.gpx`) переводятся в ноты General MIDI по стандартной таблице, это приближённое соответствие; в `.gp` (7/8) берутся ноты самого файла.
* В редакторе открываются только гитарные дорожки с 6–9 струнами; остальные дорожки (бас, клавиши, ударные…) только экспортируются в MIDI.

* Не поддерживаются файлы Guitar Pro 5 и старше (`.gp5`, `.gp4`, `.gp3`).
* Берутся только гитарные дорожки с 6–9 струнами (бас на 4 струны пока нет).
* В редакторе максимум 64 такта; при импорте длинной песни в MIDI попадает всё, а в окне показаны первые 64.
* После правки таба вручную MIDI строится уже из редактора (сетка 1/16): точная запись триолей остаётся только у неотредактированного импорта.
* Плагин не воспроизводит звук и не играет MIDI по транспорту DAW.

## Лицензия

JUCE распространяется по AGPLv3 или по коммерческой лицензии. Для личного использования проблем нет; если захотите раздавать собранный плагин другим людям, нужно либо открыть исходники под AGPLv3, либо купить лицензию JUCE.
